# Kaggle - Pandas

This repo contains the Jupyter Notebook I completed during Kaggle's "Pandas" course.

## What's in this Notebook?
* Loading datasets and selecting specific rows/columns using `loc` and `iloc`.
* Transforming data and updating column values using `.map()` and `.apply()`.
* Grouping data to extract insights and ordering results (`groupby`, `sort_values`).
* Cleaning missing values (`fillna`) and merging multiple datasets together (`concat`, `join`).
